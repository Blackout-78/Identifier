# Identifier

A private security and privacy checker for Android. Fully offline: no internet permission, nothing collected, everything stays on the phone.

## Tabs
- **Scan**: security score and findings, worst first
- **Apps**: installed apps, risky permissions, last used
- **Device**: screen lock, encryption, patch level, Wi-Fi safety
- **Settings**: color, app icon (4 styles with a color wheel), monitoring options

## Download
1. Open **[Releases](../../releases/latest)**.
2. Download the newest `Identifier-build-N.apk`.
3. Open it on your phone and tap **Install**.
